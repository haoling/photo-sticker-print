# マイルストーン

「実物のシールにズレずに刷れること」が一番のリスクなので、Immich 連携より先に印刷を固める順番にしています。

## M0: 土台づくり

- [ ] 技術スタックを決める（フロントエンド、バックエンド、PDF 生成ライブラリ）
- [ ] リポジトリの雛形、Lint / Format / テスト、CI
- [ ] Dockerfile と docker compose の例（Immich と並べて動かす想定）
- [ ] 環境変数の読み込みと、未設定時のわかりやすいエラー

**完了条件**: `docker compose up` で空のアプリが開く。

## M1: 用紙定義と印刷（写真はローカルファイルで OK）

- [ ] 用紙定義のスキーマを決める
- [ ] エーワン 29662 の用紙定義を作る（コマ位置はメーカーテンプレート＋実測）
- [ ] シートのプレビュー表示（実寸比）
- [ ] ローカル画像をコマに割り付け（仮の写真ソース）
- [ ] コマの縦横比に合わせた自動トリミング（中央合わせ）
- [ ] 塗り足し
- [ ] ブラウザ印刷（CSS `@page`）と PDF ダウンロード
- [ ] 位置補正（X/Y mm）とテスト印刷（枠線のみ）
- [ ] 印刷前のプリンタ設定案内

**完了条件**: TS7630 で 29662 に印刷し、10 コマすべてで白い隙間が出ない。用紙定義に「検証済み」が付く。

## M2: Immich 連携

- [ ] バックエンドの Immich プロキシ（許可リスト方式）
- [ ] フォトストレージのインターフェース定義と Immich 実装
- [ ] タイムラインのサムネイル一覧（無限スクロール）
- [ ] アルバム一覧・アルバム内写真
- [ ] 写真をコマへドラッグ＆ドロップ、複数選択して流し込み
- [ ] 印刷用画像の取得（プレビュー画像、解像度不足時はオリジナル）

**完了条件**: Immich の写真だけで 1 シート作って印刷できる。ブラウザの通信に API キーが一切出てこない。

## M3: PC 向け画面と編集

- [ ] 左右分割レイアウト（左: シート、右: 写真リスト / 編集 / 設定の切り替え）
- [ ] コマのクリックで編集モード
- [ ] 切り抜き（ズーム・位置調整）
- [ ] 回転（90° 単位 + 自由回転）、左右反転
- [ ] コマの入れ替え、同じ写真で全部埋める
- [ ] 作業中シートの自動保存（リロードで復元）

**完了条件**: PC ブラウザで、写真選び → 編集 → 印刷まで迷わずできる。

## M4: 設定画面とプリンタプロファイル

- [ ] プリンタプロファイル（対応用紙サイズ・フチなし可否・プロトコル）の定義
