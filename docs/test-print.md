# テスト印刷（コマの枠線）

用紙定義のコマ位置どおりに、コマの輪郭だけを刷るためのデータ。プリンタ固有の印刷位置のズレ（X/Y mm）を測るために使う。

## 取得方法

サーバーを起動して（[README](../README.md#開発)）、ブラウザで開く。用紙の `id` は `GET /api/papers` で確認できる。

| 形式 | URL |
| --- | --- |
| PDF（用紙と同じ 100×148mm、1 ページ） | `/api/papers/aone-26009/test-print.pdf` |
| PNG（600dpi、2362×3496、グレースケール） | `/api/papers/aone-26009/test-print.png` |
| SVG（mm 座標の viewBox） | `/api/papers/aone-26009/test-print.svg` |

位置補正は `offsetX` / `offsetY`（mm、-10〜10）で指定する。

```
/api/papers/aone-26009/test-print.pdf?offsetX=0.5&offsetY=-0.3
```

- コマ位置が未測定（`unmeasured`）の用紙は 409、存在しない用紙は 404、範囲外の補正値は 400 を返す。
- 文字は含まない（実行環境のフォントに左右されないため）。

## 位置補正の向き

`offsetX` / `offsetY` は **描く位置にそのまま足す**（+X は右、+Y は下）。

- 刷った枠線が、本来の位置より **左** にずれて出た → `offsetX` を **+** にする
- 本来の位置より **上** にずれて出た → `offsetY` を **+** にする

## 試し方

1. PDF を開き、**用紙サイズ: はがき、拡大縮小: 100%（実際のサイズ）** で印刷する。ページに合わせる・フチなしの自動拡大は **切る**。
2. まずは 26009 のシートに刷る（普通紙のはがきの代わり。12 枚入り）。
3. 刷ったシートを、台紙のハーフカット（コマの輪郭）と見比べる。
   - 枠線がコマの輪郭にぴったり重なれば、用紙定義とプリンタの位置が合っている。
   - ずれていたら、ずれた量（mm）を測って `offsetX` / `offsetY` に入れ、もう一度刷る。
4. 補正値が決まったら、29622 → 29662 の順に同じ補正値で確かめる。

## 確認が必要なこと

- 用紙定義のコマ位置は写真から測った推定値（`verification.source` を参照）。枠線がコマに合わないときは、プリンタのズレではなく用紙定義の誤差の可能性もある。26009 は ±0.2mm、29622 は ±0.3mm、29662 は ±0.5mm 程度。
- 10 コマで同じ向きにずれるならプリンタのズレ（補正で直せる）。コマごとにずれ方が違うなら、用紙定義の誤差か、用紙の搬送ずれ。
- フチあり印刷だと、用紙の端から約 3〜5mm は印刷されない。コマはその内側に収まっているはずだが、上下の余白（上 3mm・下 5mm とみられる）は未確認。
