# photo-sticker-print

Immich などのクラウドフォトストレージから写真を選び、エーワンなどのシール用紙に割り付けて印刷するブラウザアプリ。

- シングルユーザー前提のセルフホスト用
- 最初の対応: **Immich** / **エーワン 29662（写真シール高画質 Medium）** / **Canon PIXUS TS7630（とその仲間たち）**
